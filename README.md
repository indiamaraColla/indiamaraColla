# 👋 Olá

Meu nome é Indiamara Colla, sou desenvolvedora de software e tenho paixão por tecnologia e pela criação de interfaces eficientes e bem organizadas.
Com mais de quatro anos de experiência em desenvolvimento Front-End, tenho trabalhado em projetos desafiadores que utilizam tecnologias atuais e priorizam a melhor experiência do usuário.

# 🚀 Especialização

Estou constantemente buscando integrar técnica e colaboração, utilizando boas práticas de programação, metodologias ágeis e uma perspectiva focada em desempenho e qualidade.
Possuo experiência com React, Next.js, JavaScript, TypeScript, Redux Toolkit, Styled Components, React Query e Jest, bem como com ferramentas de observabilidade e DevOps, incluindo Azure DevOps, SonarCloud, Optimizely, New Relic e Segment.
